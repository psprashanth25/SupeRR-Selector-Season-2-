# Model V2 validation package

This package contains an alternative context-normalised analysis. It does not overwrite Model V1.

- `v2_top10_batters.csv`: alternative top 10 batters
- `v2_top10_bowlers.csv`: alternative top 10 bowlers
- `v2_batter_rankings_all.csv`: full eligible batter pool
- `v2_bowler_rankings_all.csv`: full eligible bowler pool
- `v2_validation_summary.json`: scope, Kohli audit and comparison notes
- `v2_threshold_sensitivity.csv`: pressure threshold sensitivity
- `V2_methodology_and_limitations.md`: definitions and caveats

Do not replace V1 in the dashboard until V1/V2 stability and match-level validation are completed.
